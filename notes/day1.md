# Day 1 - 指针、数组、内存基础

## 1. 指针基本概念
- 变量保存值
- 地址表示变量所在内存位置
- 指针变量用于保存地址
- `*p` 表示访问指针所指向地址中的值

## 2. 数组与内存
- 数组元素在内存中连续存放
- 相邻元素地址差值等于元素类型大小
- 在当前环境中，`sizeof(int) = 4`

## 3. 函数传参与地址
- C 语言默认值传递
- 如果函数需要修改外部变量，应传入变量地址
- 通过指针参数可以直接修改原变量内容

## 4. sizeof 与 strlen
- `sizeof` 计算变量或数组占用的总字节数
- `strlen` 计算字符串长度，不包括结尾的 `\0`

## 5. 今日结论
- `a` 是值
- `&a` 是地址
- `p` 是存地址的变量
- `*p` 是地址中的值
- 数组元素连续存储
- 指针是后续嵌入式开发的重要基础
